# VOID — кинотеатр

Сайт на русском языке: HTML, CSS и ванильный JavaScript с ES-модулями. Без npm, сборки, сервера приложения, библиотек и внешних ресурсов. Постеры и фон первого экрана хранятся в папке images. Фон искажается вокруг мыши средствами Canvas 2D; декоративные элементы и расфокус надписей сделаны на CSS. Интернет для работы сайта не нужен.

## Запуск на Mac в VS Code
1. Распакуйте архив.
2. В VS Code выберите File → Open Folder и откройте папку void-cinema.
3. В разделе Extensions установите расширение Live Server (Ritwick Dey).
4. Нажмите правой кнопкой на index.html → Open with Live Server.
5. Сайт откроется по адресу вида http://127.0.0.1:5500. Открывайте его каждый раз через Live Server: двойной клик по HTML не подходит для ES-модулей.

Live Server только раздаёт статические файлы. Серверной логики и настоящей оплаты нет.

## Файлы
- index.html — разметка и доступные подписи.
- style.css — адаптивное оформление, схемы и CSS-иллюстрации.
- data.js — фильмы «Американский психопат» (2000) и «Бойцовский клуб» (1999), цены и исходно занятые места; общая схема 4 × 6.
- storage.js — проверка, загрузка, сохранение и удаление билетов по одному ключу localStorage.
- main.js — единый state, фильтры, выбор сеанса/кресел, сумма, подтверждение и отмена.

- images/ — постеры фильмов.

## Как пользоваться
Выберите количество зрителей, при необходимости задайте максимальную цену одного билета. Фильтр оставляет сеансы, на которых хватает свободных мест. Выберите сеанс и любое количество свободных кресел. Число билетов определяется выбранными местами; поле «Мест нужно не меньше» служит только фильтром сеансов. Нажмите «Подтвердить билет». После подтверждения выбор снимается. Для нового билета снова выберите сеанс. Календарь не используется; билеты действуют до отмены.

## Проверка в браузере
1. Выберите первый сеанс. Исходно занятые кресла недоступны.
2. Выберите два места при числе зрителей 2. Сумма первого сеанса: 900 ₽. Повторный клик снимает выбор.
3. Переключите сеанс: выбор сбросится, исходная занятость будет другой.
4. Введите 0, дробное число или пустое значение зрителей: появится ошибка, подтверждение не сработает.
5. Скройте выбранный сеанс ценой ниже его стоимости: выбор снимется и появится сообщение. Сбросьте фильтры.
6. Попробуйте подтвердить без сеанса и без выбранных мест: появится ошибка. Подтвердите правильный выбор двойным нажатием: создастся один билет.
7. Обновите страницу: билет и занятость восстановятся. Отмените билет и забронируйте те же кресла снова.
8. Нажмите сброс билетов: сначала отмените диалог, затем согласитесь. Исходно занятые места сохраняются.
9. Нажимайте Tab, Shift+Tab, Enter и пробел: виден фокус, выбор кресла не уводит его с кнопки.
10. В DevTools → Application → Local Storage измените только ключ void-cinema-tickets-v1 на неверный JSON и обновите страницу: появится сообщение. Сбросьте билеты кнопкой, чтобы восстановить работу.

## Ограничения
Проект работает локально, без серверной системы бронирования и оплаты. Билеты сохраняются в текущем браузере для конкретного адреса/порта. Это локальное приложение: между разными устройствами занятость не синхронизируется. Другие вкладки того же адреса получают событие обновления; одновременные записи в localStorage не являются серверной транзакцией.

## Фотографии пространства
Раздел «Внутри VOID» — автоматически вращающаяся пространственная карусель из 11 уникальных фото на трёх уровнях. Есть стрелки, свайп и кнопка паузы. Вращение останавливается при наведении, фокусе клавиатуры и вне экрана. При системном уменьшении движения автоматическое вращение изначально выключено.
